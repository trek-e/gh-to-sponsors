<feature>
  <name>Bot Detection and Commit Classification</name>
  <files>src/github/filter.ts, src/github/filter.test.ts</files>
  <behavior>
**isBotCommit(commit: Commit): boolean**
- Returns true for author names ending in `[bot]`
- Returns true for emails containing `noreply.github.com`
- Returns true for known bot names: dependabot, renovate, github-actions
- Returns false for regular human commits
- Case-insensitive matching

Test cases:
- `{ author: "dependabot[bot]", email: "..." }` -> true
- `{ author: "renovate[bot]", email: "..." }` -> true
- `{ author: "github-actions[bot]", email: "..." }` -> true
- `{ author: "User", email: "49699333+dependabot[bot]@users.noreply.github.com" }` -> true
- `{ author: "John Doe", email: "john@example.com" }` -> false
- `{ author: "DEPENDABOT[BOT]", email: "..." }` -> true (case insensitive)

**classifyCommit(message: string): CommitType**
- Detects conventional commit prefixes: feat:, fix:, docs:, chore:, etc.
- Handles scoped commits: feat(api):, fix(auth):
- Returns 'other' for non-conventional messages
- Uses first line of message only

Test cases:
- `"feat: add login"` -> 'feat'
- `"fix(auth): resolve token issue"` -> 'fix'
- `"docs: update README"` -> 'docs'
- `"chore(deps): bump lodash"` -> 'chore'
- `"refactor: simplify logic"` -> 'refactor'
- `"test: add unit tests"` -> 'test'
- `"ci: update workflow"` -> 'ci'
- `"perf: optimize query"` -> 'perf'
- `"style: format code"` -> 'style'
- `"build: update webpack"` -> 'build'
- `"revert: undo last commit"` -> 'revert'
- `"Update README.md"` -> 'other'
- `"feat: add thing\n\nLong description"` -> 'feat' (first line only)
- `"FEAT: uppercase"` -> 'feat' (case insensitive)

**filterAndClassifyCommits(commits: Commit[]): { human: ClassifiedCommit[], botCount: number }**
- Classifies all commits
- Separates human vs bot commits
- Returns human commits with classification + bot count
  </behavior>
