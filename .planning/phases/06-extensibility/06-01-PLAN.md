<objective>
Create a shared plugin testing harness that plugin authors can use to validate their implementations comply with the PlatformPlugin interface contract.

Purpose: Without a testing harness, every plugin author must independently figure out what to test and how. The harness provides reusable test factories (makePostState) and a compliance test suite (testPlatformPluginCompliance) that validates the 4 critical plugin behaviors: name property, isConfigured() returns boolean, post() returns PostResult, and never-throw on errors.

Output: src/test-utils/ directory with plugin-harness.ts, its tests, and barrel export.
</objective>

   c. `post() returns Promise<PostResult>` - verifies result has 'success' boolean property, and if success=true has platformPostId+platformUrl, if success=false has error string
   d. `does not throw from post()` - verifies plugin.post(makePostState()) resolves (does not reject)
