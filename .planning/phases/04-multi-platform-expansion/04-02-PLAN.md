  <behavior>
BlueskyPlugin implements PlatformPlugin interface for posting teasers to Bluesky.

Test cases (input -> expected output):

isConfigured():
- (identifier: 'user.bsky.social', password: 'app-password') -> true
- (identifier: undefined, password: 'app-password') -> false
- (identifier: 'user.bsky.social', password: undefined) -> false
- (identifier: '', password: '') -> false

post(state with teaser):
- (state with teaser, mock API success) -> { success: true, platformPostId: 'at://...', platformUrl: 'https://bsky.app/...' }
- (state without teaser) -> { success: false, error: 'No teaser content' }
- (state, plugin not configured) -> { success: false, error: 'Bluesky not configured' }
- (state, grapheme > 300) -> { success: false, error: 'Post exceeds 300 graphemes: N' }
- (state, API error) -> { success: false, error: 'error message' } (no throw)
- (state, 429 rate limit) -> retries with exponential backoff

name property:
- () -> 'bluesky'
  </behavior>
  <implementation>
Follow GhostPlugin pattern from src/platforms/ghost/client.ts:

1. Create src/platforms/bluesky/client.ts:
   - Import AtpAgent, RichText from @atproto/api
   - Implement PlatformPlugin interface
   - Lazy authentication (login on first getAgent() call)
   - Use RichText class for facet detection (links, hashtags, mentions)
   - Validate grapheme length with rt.graphemeLength
   - Include langs: ['en'] (or configured defaultLang) per RESEARCH.md
   - Exponential backoff with jitter for 429s (reuse Ghost pattern)
   - Never throw from post() - always return PostResult

2. Create src/platforms/bluesky/index.ts:
   - Barrel export: `export { BlueskyPlugin } from './client.js'`

3. Mock @atproto/api in tests:
   - Mock AtpAgent with login() and post() methods
   - Mock RichText with graphemeLength, text, facets, detectFacets()

4. Post URL format: `https://bsky.app/profile/{identifier}/post/{rkey}`
   where rkey is last segment of response.uri

5. Error handling:
   - Check error.status === 429 for rate limits
   - error.message for other API errors
   - ExpiredToken, InvalidToken, AuthenticationRequired for auth errors
  </implementation>
