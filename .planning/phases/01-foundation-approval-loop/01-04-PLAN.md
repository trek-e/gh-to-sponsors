   - import { SESClient, SendEmailCommand } from '@aws-sdk/client-ses'
   - Constructor takes region and fromEmail (credentials from env)
   - send() creates SendEmailCommand with multipart body
   - Map response to EmailResult

4. src/email/sendgrid.ts - SendGrid implementation:
   - import sgMail from '@sendgrid/mail'
   - Constructor takes apiKey and fromEmail
   - send() calls sgMail.send()
   - Map response to EmailResult

   - createEmailProvider(config: EmailConfig): EmailProvider
   - Switch on config.provider ('resend' | 'ses' | 'sendgrid')
