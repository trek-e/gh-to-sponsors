  <files>

  <action>
Create state management functions for artifact-based persistence:

1. src/state/artifacts.ts:

Constants:
- DEFAULT_STATE_PATH = '.state/digest.json'
- EMPTY_STATE: DigestState = { posts: {}, usedTokens: [], lastRun: '' }

Functions:
- loadState(path?: string): Promise<DigestState>
  - Read JSON file from path (default: .state/digest.json)
  - If file doesn't exist, return EMPTY_STATE (don't throw)
  - Parse and return DigestState
  - Throw on JSON parse errors (corrupted state)

- saveState(state: DigestState, path?: string): Promise<void>
  - Ensure directory exists (mkdir -p equivalent)
  - Write state as pretty-printed JSON
  - Use atomic write pattern (write to temp, rename)

- updatePostStatus(state: DigestState, postId: string, status: PostStatus, platforms?: Record<string, PlatformResult>): DigestState
  - Return new state with updated post
  - Set approvedAt if status is 'approved'
  - Immutable update pattern (don't mutate input)

- markTokenUsed(state: DigestState, jti: string): DigestState
  - Add jti to usedTokens array
  - Return new state (immutable)

- cleanExpiredTokens(state: DigestState, maxAgeMs: number): DigestState
  - Remove tokens older than maxAgeMs from usedTokens
  - This prevents unbounded state growth
  - Call this during state save operations

- createPost(state: DigestState, post: Omit<PostState, 'createdAt'>): DigestState
  - Add new post with createdAt = new Date().toISOString()
  - Return new state (immutable)

2. src/state/index.ts:
- Re-export all functions from artifacts.ts
- Export DEFAULT_STATE_PATH constant

Implementation notes from RESEARCH.md:
- Artifacts are immutable in v4+ (we write new state each run)
- 90-day default retention (document this)
- State file is uploaded after each workflow run
- State file is downloaded at start of each workflow run
- Vercel Function will use GitHub API to download artifact (separate plan)
