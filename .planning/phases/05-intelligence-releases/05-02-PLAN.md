  <behavior>
decideCadence(state, config, hasActivity) determines the action:

Test cases:
1. mode='daily' + hasActivity -> { action: 'generate', periodType: 'daily' }
2. mode='daily' + no activity -> { action: 'skip', reason: 'No activity' }
3. mode='weekly' + correct day -> { action: 'generate', periodType: 'weekly' }
4. mode='weekly' + wrong day -> { action: 'skip', reason: 'Not weekly day' }
5. mode='auto' + hasActivity + not quiet -> { action: 'generate', periodType: 'daily' }
6. mode='auto' + no activity + 3+ quiet days -> { action: 'generate', periodType: 'weekly' }
7. mode='auto' + hasActivity + was quiet (3+ days) -> { action: 'generate', periodType: 'daily', immediate: true }

updateActivityTracking(state, hasActivity) returns new state:
1. hasActivity=true -> lastActivityDate=today, consecutiveQuietDays=0
2. hasActivity=false -> consecutiveQuietDays++ (only once per day)
  </behavior>
  <implementation>
Create src/cadence/ directory.

Interface:
```typescript
export interface CadenceDecision {
  action: 'generate' | 'skip';
  periodType: 'daily' | 'weekly';
  reason: string;
  immediate?: boolean;  // True when resuming after quiet period
}
```

decideCadence function:
- Takes DigestState, CadenceConfig, hasActivity boolean
- mode='daily': generate if hasActivity, else skip
- mode='weekly': check if today is weeklyDay (0-6), generate if yes
- mode='auto':
  - if hasActivity and consecutiveQuietDays >= quietPeriodDays: immediate=true (resumption)
  - if hasActivity: daily generation
  - if no activity and >= quietPeriodDays: switch to weekly mode
  - if no activity and < quietPeriodDays: skip

updateActivityTracking function:
- Immutable update pattern (returns new state)
- Sets lastActivityDate to today's ISO date (YYYY-MM-DD)
- Resets or increments consecutiveQuietDays
  </implementation>
</feature>
